# 丈育成语接龙

上班群里那局「龙年大吉 → 鸡年大吉 → 舞动青春 → 春天来了」，被做成了一款能轮流玩的成语接龙。

**丈育**是文盲的写法，**章鱼**是它的谐音。图标、裁判、命数都按八条触手来。

## 怎么玩

1. 两到四个人共用一台手机，轮流接。
2. **字接字**：上一句最后一个字，等于下一句第一个字。
3. **音接音**：读音对上即可，适合继续文化事故。
4. 必须是词典里的四字成语。接错、重复、不是成语、主动过，都掉一条触手。
5. **查了吧**会给提示，同时记丈育值。
6. 群聊名场面（龙年大吉、舞动青春、春天来了、吉祥三宝）会被章鱼点名。

默认座位：Cora、Amberter、Jilly、Lauraura。

## 本地运行

```bash
npm install
npm test
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000)。
